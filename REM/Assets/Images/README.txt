REM Drop-in PNG Slots
====================

Drop your own Rem PNG files into either:
1. The `Assets\Images\` folder next to `REM.exe`, OR
2. `%LocalAppData%\REM\Images\`

Supported filenames (all optional — if omitted, REM uses clean fallbacks):
- `rem-icon.png`          : Window/taskbar icon & top-left sidebar emblem (recommended 128x128+)
- `rem-welcome.png`       : Centered emblem on the Welcome screen (recommended 256x256+)
- `rem-corner.png`        : Larger artwork anchored directly above the bottom-left profile bar
- `rem-popup.png`         : Bottom-left artwork inside popups and modal dialogs
- `rem-popup-error.png`   : Optional override for Error popups
- `rem-popup-warning.png` : Optional override for Warning popups
- `rem-popup-confirm.png` : Optional override for Confirmation popups
- `rem-popup-info.png`    : Optional override for Info popups
